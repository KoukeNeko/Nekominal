## What's new

🛰️ The context card shows when a Claude Code session has Remote Control connected, with buttons to open its link on claude.ai or copy it. The card now stays open while the pointer is on it.

🪟 The Settings tab can be dragged out into a window of its own, like any other tab.

🔄 The update window looks like the app: Mica or acrylic, a title bar of its own, and the version it updates to from the start. A copy not installed with Scoop opens the release page on GitHub instead of doing nothing.

🔠 Font ligatures are on by default. Settings › Appearance still turns them off.

## Fixes

🖥️ Full screen is opaque whatever the backdrop. It shows only minimize and close, and the title bar no longer moves the window.

🔍 The settings search box lights up only once you click or type in it, and its caret blinks like the cursor.

📐 A settings row with a second line, such as the version on the About page, is centered in its row.

## 繁體中文

## 新功能與改進

🛰️ Claude Code 工作階段連上 Remote Control 時，脈絡卡片會顯示出來，並提供按鈕在 claude.ai 開啟連結或複製連結。指標停在卡片上時，卡片會保持開啟。

🪟 設定分頁可以像其他分頁一樣拖出來，成為獨立的視窗。

🔄 更新視窗改用和 app 一致的外觀：Mica 或壓克力背景、自己的標題列，一開始就顯示要更新到的版本。不是用 Scoop 安裝的版本會開啟 GitHub 上的發行頁面，而不是沒有反應。

🔠 字型連字預設為開啟，可以在「設定 › 外觀」關閉。

## 修正

🖥️ 全螢幕不論背景設定為何都是不透明的；只顯示最小化與關閉按鈕，標題列也不會再拖動視窗。

🔍 設定的搜尋框只在點擊或輸入後才會亮起，游標也會像終端機游標一樣閃爍。

📐 設定中有第二行說明的列（例如「關於」頁的版本）會置中顯示。
