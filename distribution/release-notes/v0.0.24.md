## What's new

🔔 Windows notifications: when an agent finishes, waits for you or fails, a program rings or sends a notification, or a command that ran 10 seconds or more ends (Settings › Terminal) while you are elsewhere. Clicking one brings you to its tab.

🤖 Agents panel (Ctrl+Shift+J): every pane that runs an agent, in every window, with its state, time, model, context and cost, and what Claude Code cost today. Codex, Gemini CLI and Aider are recognised too, and report when they are done through their own hooks, without touching your configuration.

🔍 Search all tabs (Ctrl+Shift+G) lists every match in every pane; Enter goes there.

📝 A printed `file:line:column` opens in your editor at that line (VS Code, Cursor, Windsurf or Zed is found by itself; Settings › Advanced takes any other command), with Ctrl+click or hint mode.

📌 Scrolled into the output of a command, its command line stays pinned at the top of the pane; a click goes back to it.

🌳 New tab in a git worktree, and saved window layouts (save, open, rename, delete from the palette, or `nekominal --layout <name>`).

🐚 Shell integration for cmd, Git Bash and WSL bash: prompt marks, the folder, and Claude Code's status line, as in PowerShell.

♻️ Restoring the session brings back the text of each pane, and a tab that ran as administrator comes back in an elevated window.

⌨️ The Shortcuts page lists every command; each shortcut can be changed or removed on its own, one more added, and all reset at once. A chord programs need (such as Ctrl+C) is taken when pressed a second time.

## 繁體中文

## 新功能與改進

🔔 Windows 通知：當 agent 完成、等待你或失敗，程式響鈴或送出通知，或執行 10 秒以上的指令結束（設定 › 終端機），而你正在別處時就會通知。點一下即可回到該分頁。

🤖 代理程式面板（Ctrl+Shift+J）：列出每個視窗中執行 agent 的窗格，以及狀態、時間、模型、context 與費用，並顯示 Claude Code 今天的花費。也會辨識 Codex、Gemini CLI 與 Aider，並透過它們自己的 hook 回報完成，不會修改你的設定檔。

🔍 搜尋所有分頁（Ctrl+Shift+G）列出每個窗格中符合的結果，按 Enter 就跳過去。

📝 輸出中的 `檔案:行:欄` 可用 Ctrl+點擊或提示模式在編輯器中開到該行（自動找到 VS Code、Cursor、Windsurf 或 Zed；設定 › 進階可填入其他指令）。

📌 捲動到某個指令的輸出時，它的指令列會固定在窗格頂端；點一下即可回到該處。

🌳 在新的 git 工作樹開啟分頁，以及儲存視窗配置（從命令選擇區儲存、開啟、重新命名、刪除，或使用 `nekominal --layout <名稱>`）。

🐚 cmd、Git Bash 與 WSL bash 的 shell 整合：提示標記、目前資料夾，以及 Claude Code 的狀態列，與 PowerShell 相同。

♻️ 還原工作階段時會帶回每個窗格的文字；以系統管理員執行的分頁會在提升權限的視窗中還原。

⌨️ 快速鍵頁面列出所有命令；每個快速鍵都能單獨變更或移除、再新增一個，也能一次全部還原。程式需要的組合鍵（例如 Ctrl+C）再按一次即可指定。
