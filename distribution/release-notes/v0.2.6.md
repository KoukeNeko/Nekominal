## Fixes

⌨️ Win+` for the drop-down window works more often:
- It now uses whichever key types a backtick on your keyboard layout, such as on a UK keyboard. It used to always be the key under Esc.
- If another program holds Win+`, such as Windows Terminal's quake mode, Nekominal tries again each time one of its windows becomes active. Once that program lets go of the key, Nekominal takes it without a restart.
- When Win+` can't work, opening the drop-down window from the command palette says why.

## 修正

⌨️ 下拉式視窗的 Win+` 更可靠：
- 現在會使用目前鍵盤配置中輸入 ` 的按鍵，例如英式鍵盤。之前固定使用 Esc 下方的按鍵。
- 如果 Win+` 被其他程式佔用，例如 Windows Terminal 的 quake 模式，Nekominal 會在自己的視窗每次啟用時重試。那個程式釋放這個鍵之後，Nekominal 不必重新啟動就會接手。
- Win+` 無法使用時，從命令選擇區開啟下拉式視窗會說明原因。
