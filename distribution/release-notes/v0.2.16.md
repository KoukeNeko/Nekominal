## Fixes

🪟 The floating panels have their own acrylic: only what lies behind each panel is blurred. In 0.2.15 their layer covered the whole window, so the acrylic blurred the terminal behind it and none showed in the panel itself.

## Lighter

🪶 While a Claude Code session runs subagents, Nekominal no longer reads every workflow's journal again each second. A workflow whose files have not changed keeps what was read last time, so a long session with many workflows costs no more at rest than a short one.

🪟 The floating panels give back their memory a few seconds after they close, instead of the moment they close. Moving the pointer between the meter and its card no longer rebuilds the panel's buffers each time.

## 繁體中文

## 修正

🪟 浮動面板現在自己有壓克力背景，只模糊面板正後方的內容。0.2.15 的面板圖層蓋滿整個視窗，結果模糊的是後面的終端機，面板本身反而看不到壓克力。

## 更輕量

🪶 Claude Code 工作階段執行 subagent 時，Nekominal 不再每秒重讀所有 workflow 的日誌。檔案沒有變動的 workflow 會沿用上一次讀到的內容，所以即使工作階段很長、workflow 很多，閒置時的負擔也和短的一樣。

🪟 浮動面板關閉幾秒後才釋放記憶體，而不是一關閉就釋放。滑鼠在計量條和它的卡片之間來回移動時，不會每次都重建面板的緩衝區。
