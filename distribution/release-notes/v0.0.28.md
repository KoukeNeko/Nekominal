## Fixes

📊 The model, context and cost of a running agent no longer drop out of the title bar. A failed look at the processes of a pane read as the shell alone at its prompt, which wiped what the agent had last said; an agent now counts as gone only once the shell has been alone for three seconds.

## 修正

📊 執行中 agent 的模型、context 與費用不再從標題列消失。先前查詢窗格的處理程序失敗時，會被誤判為只剩 shell，進而清除 agent 最後回報的資訊；現在要 shell 單獨執行滿三秒，才會視為 agent 已結束。
