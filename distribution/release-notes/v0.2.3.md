## Fixes

📊 The model and context of Claude Code show in the title bar even when a plugin's status line, or your own, takes the place of Nekominal's: Nekominal now also gives Claude Code hooks, which run beside any other, and reads the context from the session's transcript. Cost and time still need Nekominal's status line.

📊 The context card shows the tokens of the window by kind (read from the cache, written to it, new input, free) and the session's totals and lines.

🐚 With PowerShell from the Microsoft Store, what the shell starts runs outside the tab's job, so Nekominal took the agent for gone every few seconds: its numbers appeared and vanished, and the ports it listened on were missed. They are now found by their parent processes.

## 修正

📊 即使外掛或你自己的 status line 佔用了 Nekominal 的位置，標題列也會顯示 Claude Code 的模型與脈絡用量：Nekominal 另外提供 Claude Code 的 hooks（會與其他 hooks 一起執行），並從工作階段的 transcript 讀取脈絡用量。費用與時間仍需要 Nekominal 的 status line。

📊 脈絡卡片會依種類顯示視窗中的 token（從快取讀取、寫入快取、新的輸入、剩餘），以及工作階段的總量與增刪行數。

🐚 使用 Microsoft Store 版 PowerShell 時，shell 啟動的程式會跑在分頁的 job 之外，Nekominal 因此每隔幾秒就以為 agent 已結束：數字出現又消失，監聽的連接埠也找不到。現在改由父程序找到它們。
