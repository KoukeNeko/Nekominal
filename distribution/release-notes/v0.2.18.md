## Fixes

🔤 Editing Devanagari and other Indic text at the prompt no longer leaves stray characters behind. A character typed just before a virama (`्`) put the rest of the line one column off from where the shell drew it, so after the shell redrew the line a leftover letter stayed on screen. Nekominal now groups the letters around a virama the way Windows' console does. (#3)

## 修正

🔤 在提示字元編輯天城文等印度系文字時，不會再留下多餘的字元。之前在 virama（`्`）前面打字，後面的文字會比 shell 畫的位置偏一格，shell 重畫那一行後，畫面上就留下一個多出來的字母。現在 Nekominal 對 virama 前後字母的組合方式和 Windows 主控台一致。(#3)
