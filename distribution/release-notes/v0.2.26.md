## Improvements

🐙 More tabs show the icon of the program they run. Many command-line programs have no icon of their own, so a tab now looks for one in two places. First, a related program installed beside it: `git` takes Git Bash's icon, `npm`, `npx`, `pnpm` and `yarn` take Node's, `7z` takes 7-Zip's. Failing that, the program's logo from [Simple Icons](https://simpleicons.org): `gh`, `uv`, `esbuild`, `vite` and `curl`. Logos that are almost black are drawn in the colour of the tab's text, so they stay visible on a dark tab bar. Their licences are listed in `THIRD-PARTY-NOTICES.md`.

## Fixes

🔒 A program's output can no longer read or delete files in your Temp folder through the kitty image protocol. The terminal only ever meant to read and delete the protocol's own temporary files, but a path that named them on its way to another file got through. Only files directly under `%TEMP%` were reachable.

🏷️ A tab's icon and name come again from the newest program running under its shell, as before 0.2.25.

🐚 The scripts that Nekominal writes for cmd and Git Bash are now saved whole in one step, so a shell starting at that moment never reads half of one.

## 繁體中文

## 改進

🐙 更多分頁會顯示所執行程式的圖示。很多命令列程式本身沒有圖示，分頁現在會到兩個地方找。先找裝在它旁邊的相關程式：`git` 用 Git Bash 的圖示，`npm`、`npx`、`pnpm` 和 `yarn` 用 Node 的，`7z` 用 7-Zip 的。找不到的話，就用 [Simple Icons](https://simpleicons.org) 裡這個程式的標誌：`gh`、`uv`、`esbuild`、`vite` 和 `curl`。接近黑色的標誌會改用分頁文字的顏色畫，在深色的分頁列上才看得到。這些標誌的授權列在 `THIRD-PARTY-NOTICES.md`。

## 修正

🔒 程式的輸出不能再透過 kitty 圖片協定，讀取或刪除你 Temp 資料夾裡的檔案。終端機原本只打算讀取和刪除這個協定自己的暫存檔，但一個在路徑中途提到它們、實際指向別的檔案的路徑會被放行。受影響的只有 `%TEMP%` 底下的檔案。

🏷️ 分頁的圖示和名稱，又改回取自 shell 底下最新執行的程式，和 0.2.25 之前一樣。

🐚 Nekominal 為 cmd 和 Git Bash 寫的腳本，現在會一次完整存好，同一時間啟動的 shell 不會讀到只寫了一半的檔案。
