## Improvements

🌿 The branch at the right of the title bar opens a card when you point at it, as the context meter does. The card says whether the folder is the main checkout or a worktree, which files have changes, whether its commits are pushed, and whether it is merged into the default branch. It uses the same lines as the dialog for removing a worktree. git is asked in the background, so the window never waits for it.

## 改進

🌿 游標移到標題列右邊的分支上，會打開一張卡片，和上下文計量條一樣。卡片會寫出這個資料夾是主要簽出還是工作樹、哪些檔案有變更、提交推送了沒，以及是否已合併到預設分支。內容和移除工作樹對話框裡的那幾行相同。git 在背景詢問，視窗不會因此停頓。
