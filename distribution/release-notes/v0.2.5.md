## Fixes

🪟 Nekominal starts on a fresh Windows: the C runtime is now built into `Nekominal.exe`, which no longer needs the Visual C++ redistributable (`VCRUNTIME140.dll`). Without it, earlier versions did not start at all and showed no error.

🔄 This is the first update that keeps your tabs running when you update from 0.2.4 with Update and restart.

## 繁體中文

## 修正

🪟 Nekominal 可以在全新的 Windows 上啟動：C runtime 現在已內建在 `Nekominal.exe` 中，不再需要 Visual C++ 可轉散發套件（`VCRUNTIME140.dll`）。缺少它時，之前的版本會完全無法啟動，也不會顯示任何錯誤。

🔄 從 0.2.4 用「更新並重新啟動」更新到這一版時，分頁會第一次在更新期間持續執行。
