## New

🖱️ Right-click a path or an address in a pane and a menu opens: open it, show the file in File Explorer, or copy the path or the address. It works whatever the right-click setting is.

⚙️ A new Previews page in the settings. You can turn the image preview off, and set how large it is (the longest side, 160 to 960 px).

## Improvements

🖼️ The image preview is larger by default (480 px, up from 320), has the same padding as the other cards so the acrylic shows around the picture, and never grows taller than the window.

## Fixes

🌿 The branch card no longer says "program not found" when the app's own PATH lacks the folder of git. Nekominal now starts git and gh with the PATH Windows gives a new program, as your terminal tabs have it. This also brings back the pull request badge and the worktree features in that case. If git is truly not installed, the card says git was not found.

## 繁體中文

## 新功能

🖱️ 在 pane 裡的路徑或網址上按右鍵，會打開一個選單：開啟、在檔案總管中顯示檔案，或複製路徑、網址。不管右鍵的設定是什麼，都會這樣。

⚙️ 設定裡新增「預覽」頁。可以關掉圖片預覽，也可以調整它的大小（最長邊，160 到 960 像素）。

## 改進

🖼️ 圖片預覽預設變大（480 像素，原本是 320），內距和其他卡片一樣，所以圖片四周看得到壓克力，也不會比視窗還高。

## 修正

🌿 當 app 自己的 PATH 裡沒有 git 的資料夾時，分支卡片不會再顯示「program not found」。Nekominal 現在用 Windows 給新程式的 PATH 來啟動 git 和 gh，和你的終端機分頁一樣。這種情況下，PR 徽章和工作樹功能也會恢復。如果真的沒有安裝 git，卡片會寫「git was not found」。
