## What's new

🖼️ Inline images: Sixel and the kitty graphics protocol (PNG, raw pixels, compressed and chunked transfers, placements, deletes), so `chafa`, `timg`, `yazi` and `kitty +kitten icat` show pictures. Pictures scroll with their text into the scrollback, and a program can make the terminal hold only so much. Kitty animation and Unicode placeholders are not supported yet.

🔤 Font ligatures: with a font that has them (Cascadia Code, Fira Code…), `=>` and `!=` become one glyph. Off by default; Settings › Appearance › Font ligatures. The cursor and a selection break them.

📜 The sidebar scrolls with the mouse wheel, and follows the selected tab.

## Fixes and hardening

🔒 An elevated window no longer opens the automation pipe, so a program without administrator rights cannot use it to run commands as administrator.

🔒 A new worktree types its repository's setup command and waits for you to press Enter, instead of running it.

🔒 A file name such as `$(…)` dropped or pasted into PowerShell or Git Bash is quoted so that it never runs.

🔒 A program is never looked up in the current folder through an empty entry of PATH.

🧹 "Remove this worktree" warns about git-ignored files (such as `.env`) that go with the folder.

💾 A broken `layouts.json` is no longer overwritten by a save; layouts are opened and deleted by name.

💾 Settings: a hand edit made while the window is active is no longer overwritten, a file with a mistake keeps the settings in effect and says what is wrong, and several windows saving at once no longer step on each other's file.

💾 The session is saved when Windows shuts down or you sign out.

🪟 Minimizing no longer squeezes the visible tab's terminal to two columns.

⚡ With many tabs: one process snapshot a second instead of one per tab, the git folder of a tab read once, each tab's state read once a frame; `gh` is stopped after 30 seconds and asked less often about merged or closed pull requests.

🛡️ A flood of combining marks, bells or queries can no longer freeze the window or grow its memory without limit; the command line shown in a notification loses control characters and stops at 256 characters.

🔗 Ctrl+click and hints open `.\x` and `..\x` paths.

🤖 Automation: a request that timed out is no longer carried out later, `send-text` and `close` say so when a question is already open, and `nekominal cli` refuses `-p` where it means nothing.

## 繁體中文

## 新功能與改進

🖼️ 內嵌圖片：支援 Sixel 與 kitty 圖片協定（PNG、原始像素、壓縮與分段傳送、擺放、刪除），`chafa`、`timg`、`yazi` 與 `kitty +kitten icat` 都能顯示圖片。圖片會隨文字捲進捲動歷史，程式能讓終端機保存的圖片量有上限。kitty 的動畫與 Unicode 佔位字元尚未支援。

🔤 字型連字：使用有連字的字型（Cascadia Code、Fira Code 等）時，`=>`、`!=` 會顯示為一個字形。預設關閉，在「設定 › 外觀 › 字型連字」開啟。游標與選取範圍會把連字拆開。

📜 側邊欄可以用滑鼠滾輪捲動，並會跟著選中的分頁。

## 修正與強化

🔒 以系統管理員身分執行的視窗不再開啟自動化 pipe，沒有系統管理員權限的程式無法藉此以系統管理員身分執行指令。

🔒 新建工作樹時只會輸入儲存庫的 setup 指令，等你按 Enter，不再直接執行。

🔒 拖入或貼上到 PowerShell、Git Bash 的檔名（例如 `$(…)`）會正確加上引號，不會被執行。

🔒 不會再透過 PATH 中的空項目，在目前資料夾找程式。

🧹 「移除這個工作樹」會警告會一起刪除的 git 忽略檔（例如 `.env`）。

💾 損壞的 `layouts.json` 不會在儲存時被覆蓋；配置改以名稱開啟與刪除。

💾 設定：視窗在作用中時的手動編輯不會再被覆蓋；檔案有錯時會保留目前的設定並說明哪裡有問題；多個視窗同時儲存不會再互相干擾。

💾 Windows 關機或登出時會儲存工作階段。

🪟 視窗最小化時，不會再把目前分頁的終端機壓成兩欄。

⚡ 分頁很多時：每秒只取一次程序快照而不是每個分頁一次，每個分頁的 git 資料夾只讀一次，每一幀只讀一次各分頁的狀態；`gh` 超過 30 秒會被停止，已合併或關閉的 PR 也較少重新查詢。

🛡️ 大量的組合字元、響鈴或查詢不會再讓視窗凍結或記憶體無限增加；通知裡顯示的指令會去掉控制字元，並限制在 256 個字元內。

🔗 Ctrl+點選與提示選取可以開啟 `.\x`、`..\x` 開頭的路徑。

🤖 自動化：逾時的請求不會在之後才被執行；已有詢問視窗時，`send-text` 與 `close` 會回報；`nekominal cli` 在 `-p` 沒有意義的地方會拒絕。
