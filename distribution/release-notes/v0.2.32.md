## Improvements

🔄 The About page now says how this copy is updated: with Scoop, with the installer, or by downloading the release. For Scoop and the installer it also says that your open tabs, and the programs running in them, keep running during the update. For a copy updated by hand it says the tabs end when you close it to start the new one.

## Fixes

📐 Every card of the title bar (the context meter, the subagents, the pull request and the branch) now opens at the same height under the bar, and starts at the same place relative to what opened it. The pull request card used to hang a little higher than the others.

🌿 In the branch card, the remote and the line that says whether the branch is up to date are one box, with the same padding as the lines under it. The row that opens the repository no longer sticks out past them when the pointer is on it.

## 繁體中文

## 改進

🔄 「關於」頁現在會寫出這個版本是怎麼更新的：透過 Scoop、透過安裝程式，或是手動下載新版。如果是 Scoop 或安裝程式，還會說明更新時，你現有的分頁和裡面執行的程式會繼續運作。如果是手動更新的版本，則會說明要關掉它再啟動新版，分頁會跟著結束。

## 修正

📐 標題列的每一張卡片（context 計量條、subagent、PR 和分支）現在都在標題列下方同一個高度打開，相對於開啟它的元件的位置也一致。PR 卡片以前比其他的略高。

🌿 分支卡片裡，遠端和「是否與上游同步」那一行合成一個框，內距和下面的幾行一致。游標移到「打開儲存庫」那一行時，底色也不會再比它們寬出去。
