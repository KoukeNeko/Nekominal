## What's new

📦 Each release now has an MSI installer for x64 and ARM64 beside the zip. It installs for the current user into AppData, so it needs no administrator, and it adds Nekominal to the Start menu.

🖱️ The scrollbar can be dragged. Take the thumb and the view follows it; a press on the track brings the thumb there first. The thumb is lit while it is held.

🪟 The context card, the subagents card and its drawer, and the tip beside a sidebar row now use the same blurred acrylic background as the menus.

🔔 Settings › Terminal has a test button under the Windows notifications switch. It shows a notification at once, even with the switch off, and says what went wrong if it cannot.

## Lighter

🪶 The cursor stops blinking 5 seconds after the last key, and starts again with the next one or when you come back to the window. A window nobody types in no longer wakes up twice a second to draw it, so it uses less CPU at rest than Windows Terminal.

## Fixes

🔔 Notifications keep their icon. A copy of Nekominal run with its own settings folder (a portable copy, a test) pointed every notification's icon at that folder, so the icon disappeared when the folder was deleted.

## 繁體中文

## 新功能

📦 每個版本現在除了 zip，也附上 x64 與 ARM64 的 MSI 安裝程式。它只安裝給目前的使用者，放在 AppData，不需要系統管理員權限，並會把 Nekominal 加到開始功能表。

🖱️ 捲軸可以拖曳了：抓住滑塊，畫面就跟著移動；按在軌道上，滑塊會先跳到那裡。按住時滑塊會亮起。

🪟 Context 卡片、subagent 卡片與它的抽屜，以及側邊欄分頁旁的提示，現在都和選單一樣使用模糊的壓克力背景。

🔔 「設定 › 終端機」的 Windows 通知開關下方多了測試按鈕：按下立刻發一則通知，開關關著也可以；發不出來時會告訴你原因。

## 更輕量

🪶 最後一次按鍵 5 秒後，游標就停止閃爍，下一次按鍵或回到視窗時再開始閃。沒人打字的視窗不再每秒醒來兩次重畫游標，閒置時的 CPU 用量比 Windows Terminal 更低。

## 修正

🔔 通知不會再沒有圖示。用自己的設定資料夾執行的 Nekominal（可攜版、測試用）會把所有通知的圖示指向那個資料夾，資料夾刪掉後圖示就不見了。
