## Improvements

🔗 In the branch card, the row with the remote (`KoukeNeko/Nekominal`) is a link: it lights up under the pointer and opens the repository in the browser. It also works for ssh remotes (`git@github.com:…`), which open as `https://host/path`.

🌿 The branch card and the image preview now hang from what opens them exactly as the pull request card does: the left edge a little before it, a little below it, or above it when there is no room below.

🌿 Asking git is silent: the card appears once git has answered, instead of showing "Asking git…" first, and keeps the last answer while it asks again.

## Fixes

📐 The icons in the branch card (the link next to the remote, the check marks) are centred on their line of text.

## 改進

🔗 分支卡片裡寫著遠端（`KoukeNeko/Nekominal`）的那一行是個連結：游標移上去會亮起，按下去會在瀏覽器打開這個儲存庫。ssh 的遠端（`git@github.com:…`）也可以，會以 `https://主機/路徑` 打開。

🌿 分支卡片和圖片預覽，現在和 PR 卡片一樣從開啟它的東西下面展開：左邊緣比它稍微往前、在它下方一點，下面沒有空間時就改到上方。

🌿 詢問 git 改成靜默進行：卡片等 git 回答後才出現，不會先顯示「正在詢問 git…」，重新詢問時也會沿用上一次的答案。

## 修正

📐 分支卡片裡的圖示（遠端旁的連結圖示、打勾的符號）現在和文字垂直置中。
