## Lighter

🪶 A window at rest uses next to no CPU: the list of the system's processes is no longer read every second, only when a tab prints or every 30 s.

🧠 Each tab takes less memory: smaller glyph atlases to start with, no copy of them in memory, and a smaller event queue. Five tabs now use about 136 MB, against 193 MB for Windows Terminal.

⚡ The shaders are compiled when Nekominal is built, so it no longer loads the shader compiler at every start.

## Safer with what programs print

🖼️ Pictures can no longer freeze the window: thousands of tiny Sixel or kitty pictures, or a Sixel picture that asks for millions of pixels in a few bytes, are now bounded.

🔒 A kitty picture can be loaded only from the protocol's own temporary files, so a program on another machine (over ssh) can no longer learn which of your files exist.

🔗 Long links (OSC 8) can no longer grow memory without end, and hovering a URL of thousands of `)` no longer stalls the window.

📂 A dropped or pasted file name is quoted for the program running in the tab, so `ssh` or `wsl` in a cmd tab cannot run a command hidden in a file name.

## Fixes

🔄 Update and restart: a window that hands its tabs over too late keeps them instead of losing them, a tab's own command that uses `--adopt` is left alone, and paths with curly apostrophes no longer break the update.

🤖 Claude Code, Aider and Gemini hooks work when the install path has a `'` (such as a user named O'Brien).

🗂️ A new tab no longer shows the agent state of a tab from a Nekominal that crashed, and today's cost no longer loses a session that ends at the same moment as another.

## 繁體中文

## 更輕量

🪶 閒置的視窗幾乎不用 CPU：不再每秒讀取系統的處理程序清單，只在分頁有輸出時或每 30 秒讀一次。

🧠 每個分頁用的記憶體更少：字形圖集起始較小、不再於記憶體中保留副本，事件佇列也變小。五個分頁現在約用 136 MB，Windows Terminal 為 193 MB。

⚡ 著色器在建置時就已編譯，啟動時不再載入著色器編譯器。

## 對程式輸出更安全

🖼️ 圖片不會再讓視窗卡住：數千張極小的 Sixel 或 kitty 圖片，或用幾個位元組要求數百萬像素的 Sixel 圖片，現在都有上限。

🔒 kitty 圖片只能從協定本身的暫存檔載入，另一台電腦上的程式（透過 ssh）無法再探知你有哪些檔案。

🔗 長連結（OSC 8）不會再讓記憶體無限增長，滑鼠移到含數千個 `)` 的網址上也不會再卡住。

📂 拖放或貼上的檔名會依分頁中正在執行的程式加上引號，cmd 分頁裡的 `ssh` 或 `wsl` 不會執行藏在檔名裡的指令。

## 修正

🔄 「更新並重新啟動」：太晚交出分頁的視窗會保留分頁而不是失去它們；分頁自己的指令若用到 `--adopt` 不會再被改動；路徑中有彎引號時更新不會再失敗。

🤖 安裝路徑含 `'`（例如使用者名稱 O'Brien）時，Claude Code、Aider 與 Gemini 的 hooks 也能正常運作。

🗂️ 新分頁不會再顯示當機的 Nekominal 留下的 agent 狀態；今日費用也不會因兩個工作階段同時結束而少算。
