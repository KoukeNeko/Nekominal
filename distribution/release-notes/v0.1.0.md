## What's new

🗂️ Three styles for the sidebar tabs, picked in Settings › Appearance › Sidebar tabs:
- Activity: what the agent last said or the last command, with a line of its context and cost.
- Agent cards: a card per tab with a preview of what it did, its model, context and cost.
- By repository: tabs under the repository they are in, with worktrees under their main folder and the cost of each repository.

📱 Phone notifications: Settings › Terminal › Phone notifications sends what would raise a Windows notification to an ntfy topic or any https webhook, while you are away from the PC (or always), for the events you pick. A test button shows whether it arrived.

⚡ Triggers: a page of rules that watch the output. When a line matches, highlight it, notify, mark the tab, ring, or send a reply (off until you allow it). A rule is edited in place, with a live match against the last lines of the current tab, and ready-made rules are a click away.

🔀 Pull requests and ports on the tabs: a tab in a GitHub repository shows its PR and checks (passed, failing, running, draft, merged), and every port its programs listen on. A click opens the PR or `localhost`. Needs `gh` for the PR.

🌳 Worktrees all the way: "Remove this worktree" shows what would be lost (uncommitted files, unpushed commits, whether it is merged) and offers to delete the branch or keep it, never forcing. New worktrees get the ignored files named in `.worktreeinclude` (such as `.env`) and run `.nekominal\setup.ps1` or `setup.cmd` in the new tab.

🖼️ Paste an image or drop files: pasting a screenshot saves it and types its path, so an agent can read it; files copied in Explorer or dropped on a pane type their paths too, in WSL form in a WSL tab.

🤖 Automation: `nekominal cli` (list, send-text, get-text, new-tab, split, focus, close, notify, subscribe) drives the running terminal over a named pipe only you can open, so scripts and agents can open panes and read them.

⚙️ Settings in a tab, as in Windows Terminal, with pages split into sections, one size for every row, and a page that grows with the window.

📋 The list of profiles by the new tab button is as wide as the longest name.

🐱 A new app icon.

## Fixes

🧭 A system PATH with a stray quote no longer hides the rest of PATH from programs written in Go: `gh` finds git again.

📊 Each tab of the sidebar shows its own agent's numbers and branch, not only the selected tab's.

🖱️ A click on the title bar closes its right-click menu instead of moving the window under it.

## 繁體中文

## 新功能與改進

🗂️ 側邊欄分頁有三種樣式，可在 設定 › 外觀 › 側邊欄的分頁 中選擇：
- 活動清單：顯示 agent 最後一句話或最後一個指令，下面是脈絡用量與費用。
- Agent 卡片：每個分頁一張卡，有輸出預覽、模型、脈絡用量與費用。
- 依專案分組：分頁收在所屬的儲存庫下，工作樹縮排在主資料夾下，並顯示每個儲存庫的費用。

📱 手機通知：設定 › 終端機 › 手機通知，會在你不在電腦前（或一律）時，把原本會跳出 Windows 通知的事件傳到 ntfy 主題或任何 https webhook，可以選擇要傳哪些事件。測試按鈕會顯示是否送達。

⚡ 觸發規則：監看輸出的規則頁。某行符合時可以標示、通知、標記分頁、響鈴，或回覆文字（需要你允許才會開啟）。規則直接在原地編輯，並以目前分頁最後幾行即時比對；也有現成的規則一鍵加入。

🔀 分頁上的 PR 與連接埠：位於 GitHub 儲存庫的分頁會顯示它的 PR 與檢查狀態（通過、失敗、執行中、草稿、已合併），以及程式正在監聽的連接埠。點一下即可開啟 PR 或 `localhost`。PR 需要安裝 `gh`。

🌳 完整的工作樹流程：「移除這個工作樹」會列出會遺失的東西（未提交的檔案、未推送的提交、是否已合併），讓你選擇刪除或保留分支，絕不強制刪除。新建工作樹時會複製 `.worktreeinclude` 列出的忽略檔（例如 `.env`），並在新分頁執行 `.nekominal\setup.ps1` 或 `setup.cmd`。

🖼️ 貼上圖片或拖入檔案：貼上截圖會先存檔再輸入路徑，讓 agent 能讀取；在檔案總管複製或拖到窗格上的檔案也會輸入路徑，WSL 分頁則使用 WSL 格式。

🤖 自動化：`nekominal cli`（list、send-text、get-text、new-tab、split、focus、close、notify、subscribe）透過只有你能開啟的 named pipe 操作執行中的終端機，讓腳本和 agent 能開窗格、讀取內容。

⚙️ 設定改成分頁，和 Windows Terminal 一樣：頁面分成段落、每一列大小一致，頁面也會隨視窗變大。

📋 新分頁按鈕旁的設定檔清單會依最長的名稱調整寬度。

🐱 新的 app 圖示。

## 修正

🧭 系統 PATH 中多出的引號不再讓 Go 寫的程式讀不到後面的路徑：`gh` 又找得到 git 了。

📊 側邊欄的每個分頁都會顯示自己 agent 的數字與分支，不再只有選中的分頁有。

🖱️ 點一下標題列就會關閉右鍵選單，不會在選單下拖動視窗。
