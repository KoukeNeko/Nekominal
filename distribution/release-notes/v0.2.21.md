## Fixes

📁 The folder at the right of the title bar no longer disappears when the bar gets crowded, for example when the subagent count shows up. When there isn't room for everything, the least useful pieces go first: the model name, the cost and the time, then the ports, then the branch. The folder and the subagents stay longer, and the agent's state and context meter stay longest.

🪟 The updater's window keeps its acrylic backdrop, and the text of an earlier step no longer shows through the current one. During a Scoop update this window is drawn by the version you are updating from, so you will see the fix when you update from 0.2.21 to a later version.

🤖 After an update, Nekominal waits for the window to settle and then makes each adopted pane one row smaller and gives it its size back half a second later. Programs that fill the screen, like Claude Code, get two real size changes and redraw at the right size, whatever size the new window came back at.

## 繁體中文

## 修正

📁 標題列右邊的資料夾，不會再因為空間不夠就消失，例如出現 subagent 數量的時候。放不下所有項目時，會先拿掉比較不重要的：模型名稱、費用和時間，再來是 port，然後是分支。資料夾和 subagent 會留得比較久，agent 的狀態和上下文計量條會留到最後。

🪟 更新視窗會保留壓克力背景，前一個步驟的文字也不會再從底下透出來。Scoop 更新時，這個視窗是由你更新前的那個版本畫的，所以要從 0.2.21 更新到之後的版本時，才會看到這個修正。

🤖 更新之後，Nekominal 會等視窗定下來，再把接手的每個窗格縮一列，半秒後放回原本的大小。像 Claude Code 這種佔滿整個畫面的程式會收到兩次真正的大小變化，不管新視窗是什麼大小，都會用正確的尺寸重畫。
