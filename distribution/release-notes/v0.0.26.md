## Fixes

⌨️ Ctrl+, no longer opens the settings: Microsoft Bopomofo types its full-width comma with it. Ctrl+Shift+O opens them, and the Shortcuts page can give them any other shortcut.

## 修正

⌨️ Ctrl+, 不再開啟設定，因為微軟注音用它輸入全形逗號。請改用 Ctrl+Shift+O 開啟設定，也可以在「快速鍵」頁面指定其他快速鍵。
