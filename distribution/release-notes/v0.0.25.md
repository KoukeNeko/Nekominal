## What's new

🎨 Colour schemes from the settings: under the scheme tiles, buttons import the schemes of Windows Terminal or iTerm2 presets (`.itermcolors`), and a scheme of your own can be deleted from its tile.

✂️ Snippets are edited on the Terminal page: a line each with its name and what it types (`\r` is Enter), with buttons to add and delete them.

🗂️ Saved window layouts are listed under the profiles: save this window's layout, rename, open or delete one there.

## Fixes

🤖 The agents panel (Ctrl+Shift+J) opens again.

🛡️ When the restored session has tabs that ran as administrator, the window shows first and Windows asks for them after, instead of holding up the start.

## 繁體中文

## 新功能與改進

🎨 在設定中管理色彩配置：配色方塊下方的按鈕可從 Windows Terminal 或 iTerm2 配色（`.itermcolors`）匯入，自己的配色可在其方塊上刪除。

✂️ 片段改在「終端機」頁面編輯：每個片段一行，包含名稱與要輸入的文字（`\r` 代表 Enter），並可新增與刪除。

🗂️ 已儲存的視窗配置列在「設定檔」頁面下方：可儲存目前視窗的配置，也能重新命名、開啟或刪除。

## 修正

🤖 代理程式面板（Ctrl+Shift+J）恢復可以開啟。

🛡️ 還原的工作階段含有以系統管理員執行的分頁時，會先顯示視窗再向 Windows 要求權限，不再卡住啟動。
