## Fixes

📱 Phone notifications now work with a Discord or Slack webhook. Before, Discord turned the notification down and the test button showed "curl.exe exited with 22". Each notification now also includes the title and the text in the fields those services read (`content` for Discord, `text` for Slack), cut to Discord's 2,000-character limit. Other webhooks get the same fields they got before.

🌐 The install command at the top of the website now adds the Scoop bucket first, so copying it works on a machine that has never added the bucket.
