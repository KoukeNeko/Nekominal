## What's new

🔄 Update and restart keeps your tabs running: the shells, agents (Claude Code included) and commands in every tab go on through the update and come back in the new version where they were, with their screen and scrollback. A hidden copy of Nekominal holds them while Scoop updates, and the new version takes them back. This works from the update after this one: updating to 0.2.4 itself still restarts the tabs, as 0.2.3 cannot hand them over yet.

↔️ Drag the edge of the sidebar to make it wider or narrower; the width is kept.

## Fixes

📊 The context in the title bar comes from whichever is newer, Claude Code's status line or its transcript, and the cost and time are kept from the status line's last run.

⚙️ The styles of the sidebar list show in Settings only while the tabs are a sidebar list.

🐱 `nekominal` from the command line starts Nekominal itself, with its icon, instead of a Scoop launcher without one: the app's folder is now on PATH.

🧩 The consoles of the tabs run from a copy in `%LOCALAPPDATA%\Nekominal\conpty`, so open tabs no longer stop Scoop from updating.

## 繁體中文

## 新功能與改進

🔄 「更新並重新啟動」不會中斷分頁：每個分頁裡的 shell、agent（包含 Claude Code）和指令都會在更新期間繼續執行，並在新版本的同一個位置接回，畫面與捲動歷史都保留。Scoop 更新時，由一份隱藏的 Nekominal 複本暫管分頁，新版本再接手。這從下一次更新開始生效：更新到 0.2.4 這一次仍會重新開啟分頁，因為 0.2.3 還不會交接。

↔️ 拖曳側邊欄的邊緣可以調整寬度，寬度會保留。

## 修正

📊 標題列的脈絡用量取 Claude Code status line 與 transcript 中較新的一方，費用與時間沿用 status line 最後一次的資料。

⚙️ 側邊欄清單的樣式只在分頁版面為「側邊欄 · 清單」時出現在設定中。

🐱 在命令列輸入 `nekominal` 會直接啟動帶有圖示的 Nekominal，不再經過沒有圖示的 Scoop 啟動器：app 資料夾改加入 PATH。

🧩 分頁的主控台改從 `%LOCALAPPDATA%\Nekominal\conpty` 的複本執行，開著分頁時 Scoop 也能更新。
