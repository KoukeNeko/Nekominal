## 新功能與改進

🗂️ 檔案總管的右鍵選單預設開啟「在 Nekominal 開啟」，並分成「在這裡開啟」與「以系統管理員身分開啟」兩項；在磁碟根目錄（例如 `C:\`）也會開在點選的資料夾。

🌱 新分頁的環境變數與 Windows Terminal 相同：取自 Windows 為新程式準備的環境，不再沿用啟動 Nekominal 的程式留下的變數；安裝新工具後，新分頁直接看得到新的 PATH。需要舊的行為時，可在「設定 → 進階」開啟「新分頁沿用 Nekominal 啟動時的環境變數」。

⌨️ 以下快速鍵現在都有作用：Ctrl+Shift+1～9 切換分頁、Ctrl+PageUp／PageDown 切換左右分頁、移動分頁、Ctrl+= ／ Ctrl+- ／ Ctrl+0 縮放字型、重新啟動窗格。按住不放時，移動、調整窗格大小、捲動與縮放會持續動作。

🛡️ 設為「以系統管理員身分執行」的設定檔，只會開一個提升權限的視窗，並開在要求的資料夾；拒絕 Windows 的提示時，改在原視窗以一般權限開啟。

## 錯誤修正

🤖 從 Claude Code 工作階段啟動 Nekominal 時，分頁裡的 Claude Code 也能自動更新分頁標題。

🖥️ 全螢幕與下拉視窗（Win+`）會填滿整個視窗，不再只畫在左上角。

🔒 程式印出的 `file:` 連結無法再透過 Ctrl+點選執行程式；Python、Shell、App 安裝套件等會執行程式碼的檔案一律不開啟。

🧊 大量組合字元或膚色修飾字元的輸出不再讓視窗凍結。

🎮 顯示卡驅動更新或逾時重設時，視窗會在新的裝置上重建，分頁裡的程式繼續執行，不再當掉或停住。

🔁 在磁碟上改過的 settings.json，不會再被設定視窗的舊內容覆蓋；無法讀取的設定值會被回報，不再被悄悄刪除。

📋 關閉最後一個分頁會清空工作階段；從檔案總管或工作列開啟的視窗，不會覆蓋原本儲存的分頁。

🧩 設定檔編輯器：只點進欄位不再關閉 PowerShell 的 shell integration，引數中的引號與全形空白會保留，環境變數名稱不分大小寫。

⬆️ 在關閉提示按下取消後，更新也會一併取消，不會在下次關閉時才突然執行。

🛠️ 平行建置（超過 64 個程序）時，分頁不再誤顯示為閒置。
