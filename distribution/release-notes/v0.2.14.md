## What's new

🤖 Subagents and workflows of a Claude Code session are shown. The title bar says how many subagents run and how many have ended, its card lists every subagent and the phases of every workflow, and each row of the sidebar shows how many subagents its tab's agent runs.

🔎 A row of the card opens a drawer: what the subagent was asked, the tools it called and what it said, or, for a workflow, its phases and agents.

## Lighter

🪶 Claude Code no longer starts Nekominal once for every tool call of every subagent. The hook that did it is gone, so an agent that runs many subagents costs less.

## Fixes

🪟 Where Claude Code finds no Git Bash and runs its hooks in PowerShell, Nekominal's hooks now run. They were written as a quoted path followed by an argument, which PowerShell cannot run, so each of them ended in a parser error.

## 繁體中文

## 新功能

🤖 Claude Code 工作階段的 subagent 與 workflow 現在看得到：標題列會顯示有幾個 subagent 在執行、幾個已結束，卡片列出每個 subagent 與每個 workflow 的各個階段，側邊欄的每一列也會標出該分頁的 agent 正在執行幾個 subagent。

🔎 點卡片的任何一列會打開抽屜：看 subagent 被交辦什麼、呼叫了哪些工具、回了什麼；若是 workflow，則看它的各個階段與 agent。

## 更輕量

🪶 Claude Code 不再為每個 subagent 的每一次工具呼叫都啟動一次 Nekominal：做這件事的 hook 已經移除，所以同時執行許多 subagent 的 agent 負擔更小。

## 修正

🪟 Claude Code 找不到 Git Bash、改用 PowerShell 執行 hooks 時，Nekominal 的 hooks 現在能正常執行。它們原本寫成「加引號的路徑加一個參數」，PowerShell 無法執行這種寫法，每一個 hook 都以解析錯誤收場。
