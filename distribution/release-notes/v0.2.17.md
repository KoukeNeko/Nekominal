## Fixes

🌳 A branch name with a part Windows keeps for a device (`aux`, `con`, `nul`, `prn`, `com1`–`com9`, `lpt1`–`lpt9`, in any case, also as `aux.txt`) is refused as you type it, and the field says why. Before, git failed partway through and showed its own error. (#4)

📦 A `.worktreeinclude` that names thousands of files copies all of them into the new worktree. Before, a long list copied nothing and gave no warning. If a copy still fails, the worktree is made anyway and a notice names the file that could not be copied. (#5)

📂 Duplicating a tab or restoring a session in a folder longer than 258 characters opens the tab in the nearest parent folder short enough for Windows to start a shell in. Before, no tab opened at all. (#6)

## 修正

🌳 分支名稱只要有一段是 Windows 保留給裝置的名稱（`aux`、`con`、`nul`、`prn`、`com1`–`com9`、`lpt1`–`lpt9`，不分大小寫，`aux.txt` 這種也算），輸入時就會擋下並說明原因。之前 git 會做到一半失敗，直接顯示它的英文錯誤。(#4)

📦 `.worktreeinclude` 列出幾千個檔案時，會全部複製到新的工作樹。之前清單一長就什麼都沒複製，也沒有任何提示。如果複製還是失敗，工作樹照樣建立，並跳出通知說明哪個檔案沒複製到。(#5)

📂 在超過 258 個字元的資料夾裡複製分頁或還原工作階段時，分頁會開在最近一層 Windows 能啟動 shell 的上層資料夾。之前分頁根本不會出現。(#6)
