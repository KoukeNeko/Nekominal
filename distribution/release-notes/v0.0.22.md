## What's new

📋 Select or copy a command's output from the command palette: "Select command output" picks what the last command printed, and pressing it again goes to the command before. "Copy command output" copies the last one at once. Commands that failed get a red mark on the scrollbar. The PowerShell integration now marks where each command's output starts.

🔤 Hint mode (Ctrl+Shift+E): every URL, file path (with its `:line:col`) and git hash on the screen gets a one-letter label. Type the label to copy it, Shift+label to open it.

🎨 Colour schemes of your own: add them to `"schemes"` in settings.json in Windows Terminal's format, or run "Import color schemes from Windows Terminal" from the command palette. They appear after the built-in schemes everywhere you pick one.

💻 An ARM64 build: each release now has a zip for ARM64 next to the x64 one, and Scoop installs the one that fits the machine.

## Fixes

📍 While Claude Code runs, the title bar keeps showing the git branch and the folder next to the model, context and cost. The folder setting is now honoured.

🗂️ With the sidebar grouped by state, finished agents have a "Done" group of their own instead of sitting under "Other" with idle shells, and a bell or a notification from a tab out of sight goes with the tabs that wait for you.

📖 A new README in English and Traditional Chinese.

## 新功能與改進

📋 從命令選擇區選取或複製指令的輸出：「選取指令輸出」會選取上一個指令印出的內容，再按一次就換成前一個指令；「複製指令輸出」直接複製上一個指令的輸出。失敗的指令在捲軸上會有紅色標記。PowerShell 的 shell integration 現在會標記每個指令輸出的起點。

🔤 提示選取（Ctrl+Shift+E）：畫面上的每個網址、檔案路徑（含 `:行:欄`）與 git 雜湊都會有一個字母標籤，輸入標籤就複製，Shift+標籤則開啟。

🎨 自訂色彩配置：以 Windows Terminal 的格式加到 settings.json 的 `"schemes"`，或從命令選擇區執行「從 Windows Terminal 匯入色彩配置」。在所有可以選配色的地方，它們都會列在內建配色之後。

💻 ARM64 版本：每個版本現在除了 x64，也有 ARM64 的 zip，Scoop 會自動安裝符合電腦的那一個。

## 錯誤修正

📍 Claude Code 執行時，標題列在模型、context 與費用旁邊會繼續顯示 git 分支與資料夾；「資料夾」設定現在也會生效。

🗂️ 側邊欄依狀態分組時，已完成的 agent 有自己的「已完成」群組，不再和閒置的 shell 一起放在「其他」；看不到的分頁響鈴或發出通知時，會歸到等你回應的分頁。
