## Fixes

🏷️ A tab's icon and name now come from the program its shell started, not from the newest process anywhere under it. Before, a dev server's esbuild, or a `gh` that Claude Code ran, would take over the tab, and the tab lost its icon. Programs started through a `.cmd` shim, like `claude.cmd`, are still seen as the program they start.

## 修正

🏷️ 分頁的圖示和名稱，現在取自 shell 直接啟動的那個程式，不再是它底下任何一個最新的程序。之前 dev server 的 esbuild，或 Claude Code 執行的 `gh`，會把分頁蓋過去，分頁的圖示也跟著不見。透過 `.cmd` shim（例如 `claude.cmd`）啟動的程式，還是會被認成它實際啟動的那個程式。
