## Fixes

🔄 Updating from the app no longer fails with "the item is in use": the update no longer runs from inside the app's folder when Nekominal was started from its Scoop shortcut, and it waits for every program running from that folder. If an update failed this way before, close Nekominal and run `scoop update nekominal` once.

## 繁體中文

## 修正

🔄 從 app 內更新不會再因「正在使用中」而失敗：從 Scoop 捷徑啟動 Nekominal 時，更新不再在 app 的資料夾裡執行，並會等待所有從該資料夾執行的程式結束。如果之前因此更新失敗，請關閉 Nekominal 後執行一次 `scoop update nekominal`。
