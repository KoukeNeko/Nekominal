## New

🛡️ **Run one command as administrator without leaving the shell.** `nekominal-sudo winget upgrade --all` asks Windows once, then runs the command in the same pane, in the folder the shell is in, and hands its exit code back. What the command prints shows in the pane, what you type reaches it, and Ctrl+C stops it. The shell, its variables and what runs in it are left alone. With Scoop it is on your PATH like `nekominal`; with the installer or the zip it sits in the app's folder. Its input and output cannot be redirected, and the command gets the environment Windows gives an administrator's program, not your shell's variables.

⬆️ **Elevate this pane** (command palette, and the menu of a tab). The shell of the focused pane starts again as administrator, in the same pane, in the folder it was in, under the text it showed, in a window that is not run as administrator. The old shell, and what runs in it, ends, so a pane that runs something asks first. While a pane runs as administrator the shield shows in the tab strip, and the pane takes only what you type: the automation API (`send-text`, `get-text`, command lines in events), the broadcast of a tab and send triggers leave it alone, and an update does not carry it over. Any program of yours that can type into this window could drive an administrator's shell, which is why it stays out of reach of the rest.

🪟 **Open an administrator window here** (command palette, and the menu of a tab) opens a window run as administrator with the profile of the focused pane, in the folder it is in.

## Fixes

🖥️ Where the system draws no backdrop (Windows Server before 2025, a Remote Desktop session, or "Transparency effects" turned off) the window is now painted flat. Before, the frame it extends over the window showed through the translucent terminal. It follows the system when a Remote Desktop session begins or ends.

🔌 Where UAC is off (as it often is on a Server) the automation API and `nekominal cli` now work in a window run as administrator. They were switched off in every such window, although nothing separated it from your other programs.

📏 The menu of a tab is as wide as its longest row, and the lists that fit their width no longer cut a row that has no shortcut at the right edge.

## 繁體中文

## 新功能

🛡️ **不離開 shell，只讓一個指令以系統管理員身分執行。** `nekominal-sudo winget upgrade --all` 會請 Windows 確認一次，然後在同一個窗格、shell 所在的資料夾執行這個指令，並傳回它的結束碼。指令印出的內容顯示在窗格裡，你打的字會送進它，Ctrl+C 可以中止它；shell、它的變數和裡面執行的程式都不會被動到。用 Scoop 安裝時，它和 `nekominal` 一樣在 PATH 上；安裝程式和 zip 版則放在程式的資料夾。它的輸入與輸出不能重導向，指令拿到的是 Windows 給系統管理員程式的環境，不是你 shell 的變數。

⬆️ **將這個 pane 提權**（命令選擇區，以及分頁的選單）。聚焦窗格的 shell 會以系統管理員身分重新啟動：在同一個窗格、原本的資料夾、保留畫面上的文字，而視窗本身不必以系統管理員身分執行。舊的 shell 和裡面執行的程式會結束，所以窗格裡有程式在跑時會先問你。窗格以系統管理員身分執行期間，分頁列會顯示盾牌，而且它只接受你自己打的字：自動化 API（`send-text`、`get-text`、事件裡的指令列）、分頁的廣播和觸發器的送出都不會碰它，更新時也不會把它帶到新版。能對這個視窗打字的任何程式都可能操作一個系統管理員的 shell，所以要把它和其他程式隔開。

🪟 **在這裡開啟系統管理員視窗**（命令選擇區，以及分頁的選單）會用聚焦窗格的 profile，在它所在的資料夾，開一個以系統管理員身分執行的視窗。

## 修正

🖥️ 系統沒有畫背景材質的地方（Windows Server 2025 以前、遠端桌面工作階段，或關閉了「透明效果」），視窗現在畫成不透明。以前，延伸到視窗上的框架會從半透明的終端機底下露出來。遠端桌面工作階段開始或結束時，視窗會跟著系統變化。

🔌 UAC 關閉的地方（Server 上常是這樣），自動化 API 和 `nekominal cli` 現在可以在以系統管理員身分執行的視窗使用。以前每一個這樣的視窗都把它們關掉，但那裡其實沒有任何東西把它和你其他的程式隔開。

📏 分頁的選單和最長的一列一樣寬，依寬度調整的清單也不再把沒有快速鍵的那一列在右邊切掉。
