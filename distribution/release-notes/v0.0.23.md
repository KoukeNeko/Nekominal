## What's new

🎨 Import iTerm2 colour presets: run "Import iTerm2 color presets (.itermcolors)" from the command palette and pick one file or several, such as those of [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes). Each becomes a colour scheme of your own, named after its file; importing a file again updates its scheme.

## 新功能與改進

🎨 匯入 iTerm2 色彩配置：從命令選擇區執行「匯入 iTerm2 色彩配置（.itermcolors）」，選擇一個或多個檔案，例如 [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) 收錄的配色。每個檔案都會成為一個自訂配色，以檔名命名；再次匯入同一個檔案會更新該配色。
