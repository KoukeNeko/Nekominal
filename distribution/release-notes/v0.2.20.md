## New

🔀 Hovering a pull request's badge (`#125`) opens a card for it, the way the context meter does: its state and title, its branches, the lines it adds and removes, who opened it, its checks with the names of those that failed, its review, and what keeps it from merging. The card has buttons to open it on GitHub, copy its link, or dismiss its badge.

📏 When your Claude Code settings set an auto-compact window (`autoCompactWindow`, for one model or for all), the context meter and the context card mark where Claude Code will compact, and the card says how many tokens are left before it does.

📰 The About page shows what's new, read from the releases on GitHub: the notes of every version after yours when a newer one is out, or of your version when you are up to date.

## Fixes

⚙️ A settings tab that was open during an update comes back after it, at the same place and on the same page, instead of the window coming back on a terminal tab.

🤖 Claude Code redraws its screen after an update hands its tab over. Before, it kept its old layout until you resized the window.

🧮 Subagents that you stopped, and Claude Code's observer agents once they stop, are no longer counted as running.

🈶 Chinese text in cards and on the About page wraps at the edge of the line, instead of moving a whole run of Chinese down to the next line after a space.

🌐 The updater's window speaks the language you chose in Nekominal, not your Windows language.

## 繁體中文

## 新功能

🔀 滑鼠停在 PR 徽章（`#125`）上會打開它的卡片，用法和上下文計量條一樣。卡片會顯示 PR 的狀態和標題、分支、新增和刪除的行數、開 PR 的人、檢查結果（並列出失敗檢查的名稱）、審查狀態，以及合併前還卡在哪裡。卡片上有按鈕可以在 GitHub 開啟、複製連結，或隱藏這個徽章。

📏 如果你在 Claude Code 的設定裡指定了自動壓縮的視窗（`autoCompactWindow`，可以針對單一模型或全部模型），上下文計量條和上下文卡片會標出 Claude Code 會在哪裡壓縮，卡片也會寫出還差多少 token。

📰 「關於」頁會顯示 GitHub release 上的更新內容：有新版時列出比你目前版本新的每一版，已是最新版時則顯示你這一版的內容。

## 修正

⚙️ 更新時開著的設定分頁，更新後會回到原本的位置和頁面，不會再變成一個終端機分頁。

🤖 更新把分頁交給新版後，Claude Code 會重畫畫面。之前要手動調整視窗大小，它才會恢復正常。

🧮 你停掉的 subagent，以及停止後的 Claude Code observer agent，不會再被算成「執行中」。

🈶 卡片和「關於」頁裡的中文會在行尾換行，不會再因為前面有一個空白，就把整串中文移到下一行。

🌐 更新程式的視窗會使用你在 Nekominal 設定的語言，而不是 Windows 的系統語言。
