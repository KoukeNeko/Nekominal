## Fixes

🗂️ Opening a folder on a network drive as administrator now starts there. A mapped drive such as `Z:` belongs to your own sign-in session, so a window run as administrator does not have it, and the shell fell back to your home folder. Nekominal now starts it in the share behind the drive (`\\server\share\folder`), which a window run as administrator can open. It reads the share from your saved connections, and from the drive itself when the window that opens the administrator window can still see it.

This covers PowerShell. `cmd` cannot start in a network path, and a drive that is not saved for reconnection at sign-in, opened from Explorer's menu as administrator, still falls back to your home folder.

## 繁體中文

## 修正

🗂️ 以系統管理員身分打開網路磁碟機上的資料夾，現在會從那個資料夾開始。像 `Z:` 這樣對應出來的磁碟機屬於你自己的登入工作階段，系統管理員視窗沒有它，所以 shell 以前會退回家目錄。Nekominal 現在改用磁碟機背後的共用路徑（`\\伺服器\共用\資料夾`）來啟動，這是系統管理員視窗打得開的。共用路徑會從你儲存的連線讀取，如果開啟系統管理員視窗的那個視窗還看得到這個磁碟機，也會直接從磁碟機查。

這適用於 PowerShell。`cmd` 無法以網路路徑開始；而沒有勾「登入時重新連線」的磁碟機，如果是從檔案總管的選單以系統管理員身分開啟，仍然會退回家目錄。
