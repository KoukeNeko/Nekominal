## New

🖼️ Point at the path of an image in a pane and the picture appears under it, with its file name and size in pixels. PNG, JPEG, GIF, BMP, WebP, TIFF and icons are shown, decoded by Windows itself. The preview goes away when the pointer leaves the path.

## Improvements

🌿 The branch card in the title bar now starts with where the branch pushes: the remote by its host and repository (`github.com · KoukeNeko/Nekominal`) and whether the branch is up to date with its upstream, or how many commits it is ahead and behind. Under that come the last commit with its author and age, the changed files, the commits the remote has that you have not pulled yet, whether the branch is merged, its pull request and its stashes.

## Fixes

🩺 When git cannot read a folder, the branch card now shows what git said instead of a general message, and writes it to the log. Before, the card only said that git could not read the folder.

## 繁體中文

## 新功能

🖼️ 游標移到 pane 裡的圖片路徑上，下方會顯示這張圖，附上檔名和像素尺寸。支援 PNG、JPEG、GIF、BMP、WebP、TIFF 和圖示，由 Windows 本身解碼。游標離開路徑，預覽就消失。

## 改進

🌿 標題列的分支卡片，現在最上面先寫這個分支推送到哪裡：遠端的主機和儲存庫（`github.com · KoukeNeko/Nekominal`），以及是否已和上游同步，或是領先、落後幾個提交。下面依序是上一個提交（作者和多久以前）、有變更的檔案、遠端上還沒拉下來的提交、是否已合併、它的 PR 和 stash。

## 修正

🩺 git 讀不到資料夾時，分支卡片現在會顯示 git 實際的錯誤訊息，並寫進 log。以前卡片只會說 git 無法讀取這個資料夾。
