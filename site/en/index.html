Light by design

One native program of about 9 MB: Rust, Direct3D 11 and ConPTY. There is no Electron, no web view and no runtime to install. A window draws only when something on it changes, so a terminal you are not looking at costs next to nothing.

Knows what your agents are doing

Run Claude Code, Codex, Gemini CLI or Aider in a tab and the tab says whether it is working, waiting for you, done or failed. The sidebar groups the tabs by state, the title bar counts the ones that wait, and Ctrl+Shift+U takes you to the next of them. Nothing to set up.

The context, at a glance

For Claude Code, the title bar shows the model, the share of the context used, the cost and the time. Hover the meter to see how much is read from cache, written to cache and new input, and the tokens and lines of the session.

When the session has a Remote Control link, you can open or copy it there.

The subagents card

The title bar counts how many subagents run and how many have ended, and each row of the sidebar shows how many its tab's agent runs.

Open the card to see what every subagent is doing, and the phases of every workflow.

Open one to see what it did

A row of the card opens a drawer: what the subagent was asked, the tools it called and what it said. For a workflow, its phases and agents.

Made for parallel work

One worktree per agent

Open a tab in a new git worktree from the command palette; removing it shows what would be lost first.

Updates keep your tabs running

Update and restart, and every shell and agent carries on in the new version.

Pull requests and ports on the tabs

And phone notifications through ntfy or a webhook when an agent needs you.

Scriptable

nekominal cli lists, opens, splits and reads panes, so your own tools can drive it.

A terminal first

Split panes, tear-off tabs, a drop-down window on Win+`, saved layouts and session restore. Hints for URLs, paths and hashes, file:line opened in your editor, search across all tabs. Sixel and kitty images, font ligatures, Mica and acrylic, and colour schemes imported from Windows Terminal and iTerm2.
