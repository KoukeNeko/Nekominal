天生輕量

約 9 MB 的原生程式：Rust、Direct3D 11 與 ConPTY。沒有 Electron、沒有 web view，也不用另外安裝執行環境。視窗只在畫面有變化時才重繪，你沒在看的終端機幾乎不花資源。

82 MB一個分頁的記憶體Windows Terminal 113 MB
136 MB五個分頁的記憶體Windows Terminal 193 MB
0.70 秒啟動到 shell 開始執行Windows Terminal 0.76 秒
0.02 秒閒置時每 20 秒的 CPUWindows Terminal 0.09 秒

在 Windows 11 上與 Windows Terminal 1.24 比較，兩者皆為預設設定並執行 pwsh -NoProfile，取三次的中位數。記憶體為終端機本身與其 OpenConsole 的 working set，不含 shell。

知道你的 agent 在做什麼

在分頁裡執行 Claude Code、Codex、Gemini CLI 或 Aider，分頁就會顯示它是工作中、等你回應、已完成還是失敗。側邊欄依狀態分組，標題列會數出有幾個在等你，按 Ctrl+Shift+U 就跳到下一個。不用另外設定。

使用 Claude Code 時，標題列還會顯示模型、context 用量、費用與時間；工作階段連上 Remote Control 時，也能在那裡開啟或複製連結。

為平行工作而做

每個 agent 一個 worktree

從命令選擇區在新的 git worktree 開分頁；移除前會先告訴你會失去什麼。

更新時分頁不中斷

按「更新並重新啟動」，每個 shell 與 agent 都會在新版本中繼續執行。

分頁上看得到 PR 與 port

agent 需要你時，可透過 ntfy 或 webhook 傳到手機。

可用腳本控制

nekominal cli 能列出、開啟、分割與讀取窗格，讓你自己的工具來操作它。

首先是一個好用的終端機

分割窗格、拖出分頁、Win+` 下拉視窗、儲存版面與還原工作階段。網址、路徑與 hash 的提示模式，在編輯器開啟 file:line，搜尋所有分頁。Sixel 與 kitty 圖片、字型連字、Mica 與壓克力背景，並可匯入 Windows Terminal 與 iTerm2 的配色。

下一個等你的分頁CtrlShiftU
命令選擇區CtrlShiftP
向右分割AltShiftD
搜尋所有分頁CtrlShiftG
提示模式CtrlShiftE
設定CtrlShiftO

所有命令都能在命令選擇區找到，所有快速鍵都可以在設定中修改。

安裝

scoop bucket add koukeneko https://github.com/KoukeNeko/scoop-bucket
scoop install koukeneko/nekominal

也可以下載 zip，解壓後執行 Nekominal.exe。支援 Windows 11，x64 或 ARM64。
